## 三件事决定你该买哪台

### 一、线路：路由怎么走，比带宽数字重要

香港到大陆的网络，按优化程度大致可以排出一条梯度：

**三网直连精品（CMI / CU2 / CN2）** 是最省心的选择。以丽萨主机这条线为例，电信去程走 CN2 精品线路，联通去程走 9929，移动去程走 CMIN2，三家运营商各自走较短路径进入香港；回程统一走 CMI 大陆优化。它做到的是“三家都不吃亏”，而非“某一家特别快”。

**CN2 GIA** 是电信的顶级专线，电信宽带用户延迟极低，但联通和移动用户走这条路并不占优。**CMI** 是中国移动国际精品线，近几年扩容明显，对联通、移动用户友好，电信稍弱。**9929（CUII）** 是联通精品网，只有联通用户体验好。**普通 BGP** 靠公网自动选路，延迟均衡但高峰期不如专线稳定。

怎么选取决于你自己家的宽带。电信用户可以在 CN2 和“三网直连”之间挑；联通、移动用户优先看 CMI 或三网直连。**如果不确定，或者团队里三种宽带都有人用，就直接选三网直连，覆盖面最广，最不容易踩坑。**

延迟方面，丽萨主机官网对三网直连线的标称是“平均 50ms 左右”，多篇第三方测评给出的区间大致在 40～55ms，高峰期会升一些。这个数字只能当参考区间看，实际体验跟你所在城市和运营商有关。

### 二、IP 属性：它决定你能否打开港区服务

这一点对很多人来说比线路还关键，却最容易被忽略。IP 大致分三档：

**原生 IP** 的归属地是真实的香港，Netflix、Disney+ 港区可以直接开，不用额外调整设置。**住宅 IP / 双 ISP IP** 来自香港本地宽带运营商（比如和记电讯 HGC、有线宽屏 iCable），纯净度比机房 IP 高一档，TVB 直播、Cityline 购票这类本地化服务能正常访问。**数据中心 IP** 最便宜，但流媒体平台对它的识别率高，Netflix 经常直接返回错误页。

有个具体后果值得说清楚：如果你买的是机房 IP 的便宜香港 VPS，很可能连 Netflix 港区的门都进不去——这不是配置问题，是 IP 属性问题，加钱升配也解决不了。

同时也要说句实话：住宅 IP 不是永久通行证。它的优势在于 IP 属性纯净，但具体解锁能力取决于平台的风控规则，会随平台更新变化，这是整个行业的共性，不是某一家的问题。

### 三、配置与价格：香港贵，是有原因的

香港机房的机柜和带宽成本本来就比美西高一个量级，同配置贵一些是行业现实。市场大致价位是：1 核 1G 的入门方案月付 80～90 元能跑大多数轻量场景，2 核 2G 月付 180 元上下可以同时跑建站和代理。低于这个区间还想有大陆优化线路，基本不现实。

## 常见问题

**KVM 和 OpenVZ 选哪个？**
KVM 是完整硬件虚拟化，每个实例有独立内核，CPU 时间、内存、存储独占，跑 Docker、WireGuard、自定义内核模块都没限制。OpenVZ 共享宿主内核，这些都受管控。日常使用选 KVM，兼容性和稳定性可控；除非预算极度有限、只跑最简单的脚本，才考虑 OpenVZ。丽萨主机全线是 KVM。

**三网直连和纯 CN2 GIA 哪个更好？**
看你自己的宽带。电信用户纯 CN2 延迟可能更低；联通、移动用户三网直连更均衡。团队里混用多家运营商，或者不确定，就选三网直连。

**住宅 IP 真能看 TVB 吗？**
HGC 和 iCable 的 IP 都来自香港本地宽带运营商，TVB 直播、Cityline 购票这类服务能正常访问，这是普通机房 IP 做不到的。但具体状态受平台风控策略影响，会变化。

**流量用超了会直接断网吗？**
一般是触发限速，不是硬断，具体看套餐说明。用量大或不稳定，直接选不限流量款。

**多久能开通？**
付款后系统自动部署，不需要人工审核。控制台是中文的，拿到 IP 就能 SSH。

**香港 VPS 需要备案吗？**
不需要。香港不在大陆备案体系内，建站可以直接部署。
